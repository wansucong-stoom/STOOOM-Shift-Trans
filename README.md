# STOOM Shift Translator

## v0.6 TSF 시험판 · 기존 설치 위에 업데이트

`STOOM-Translator-v06-TSF-setup.exe`를 실행하면 v0.5 설치와 같은 AppId·위치를 사용해 업데이트합니다. **기존 프로그램을 삭제할 필요가 없습니다.** 이전 설치 위치와 바로가기 선택을 재사용하며 `%LOCALAPPDATA%\STOOMShiftTranslator05\models`의 언어팩과 같은 폴더의 `settings.json`을 유지합니다. 설치·제거 스크립트는 이 데이터 폴더를 지우지 않습니다. 구버전이 자동 종료 요청을 지원하지 않으면 트레이에서 **종료**한 후 설치 화면의 다시 시도를 누르세요.

설치 파일에는 선택 가능한 **Windows TSF 입력 지원**이 포함됩니다. 이 구성요소만 관리자 승인을 받아 보호된 Program Files 폴더에 등록하며, 번역 앱은 원래 사용자 권한으로 실행합니다. TSF는 32비트와 64비트 모듈을 모두 설치합니다. 설치 후 실행 중이던 편집기는 다시 열어야 새 모듈이 적용될 수 있습니다. 언어팩 다운로드는 다시 할 필요가 없습니다.

TSF 경로는 Windows가 제공하는 `ITfContext`와 `ITfRange`를 이용해 선택한 글 또는 현재 문단을 읽고 `SetText`로 직접 교체합니다. 클립보드와 Ctrl+A/C/V를 사용하지 않습니다. 기존 Microsoft 한글/일본어 입력기를 대체하는 키보드 서비스로 등록하지 않고 별도의 보조 범주로 등록합니다. 기존 Shift/Ctrl 더블탭 감지와 오프라인 모델은 그대로 사용합니다.

TSF 연결이 없는 입력창은 기존 UI Automation 경로를 사용합니다. **TSF에서 보안·원문 변경·적용 실패가 확인된 경우에는 더 느슨한 경로로 우회하지 않습니다.** 적용 응답이 불확실할 때 중복 삽입을 막기 위해 다시 붙여넣지 않습니다. 설정 화면의 입력 지원 상태로 실제 사용한 경로를 볼 수 있습니다.

한글 조합 중에는 최대 약 1.2초 범위에서 짧게 다시 확인하고, 정상 문맥에서는 고정 1~2초 대기를 추가하지 않습니다. 번역 중 원문·선택·포커스가 바뀌면 교체를 중단하며, 비밀번호·비공개·PIN·읽기 전용 문맥을 거부합니다. 문단은 최대 8,000 UTF-16 단위, 번역문은 최대 16,000 단위입니다. 구조화된 객체가 섞였거나 완전한 문단 경계를 읽을 수 없으면 일부만 바꾸지 않습니다.

**검증 구분:** 실제 Windows `msctf.dll`을 사용하는 테스트 소유 문서에서 32·64비트 범위 교체와 보호 조건을 검증했고, 서비스의 반복 활성화/해제 및 Python 통신을 검사했습니다. 설치된 보조 프로필이 Microsoft IME와 함께 모든 앱에서 자동 활성화되는지, Threads·ChatGPT·한컴 한글·Store 앱에서 실제 동작하는지는 아직 검증되지 않았습니다. TSF를 제공하지 않는 사용자 정의 입력창, 다른 권한 수준 및 AppContainer까지 지원한다고 보장하지 않습니다. 상세 결과와 재현 명령은 [TSF 검증 기록](native_tsf/TEST_RESULTS.md)에 있습니다.

Windows에서 입력 중인 텍스트를 오프라인으로 번역하는 **실험용** 프로그램입니다. Shift 두 번과 Ctrl 두 번에 각각 다른 목표 언어를 설정할 수 있습니다.

> 완성된 범용 입력기가 아닙니다. Threads, Codex 한글 편집기, 한컴 한글에서의 텍스트 읽기·교체와 보안 입력창 차단은 실제 환경에서 검증되지 않았습니다. 중요한 문서나 비밀번호에서는 사용하지 말고 임시 텍스트로 먼저 시험하세요.

## 사용

1. Windows 64비트에서 빌드된 EXE를 실행합니다. 사용 PC에 Python을 별도로 설치할 필요는 없습니다.
2. **언어팩 관리**에서 방향별 목록으로 사용할 모델을 하나 선택하고, 설치가 필요한 방향을 체크해 내려받습니다. 선택은 번역 엔진 설정과 연결됩니다. 첫 다운로드에는 인터넷이 필요하며, 설치된 팩은 이후 버전에서도 재사용합니다.
3. **단축키 설정**에서 Shift 두 번과 Ctrl 두 번에 목표 언어 또는 사용 안 함을 지정합니다. 시작 시 설정된 각 목표 언어마다 사용 가능한 한 방향으로 시험 번역한 뒤 준비 완료 알림을 표시합니다. 다른 방향은 처음 사용할 때 추가 로딩될 수 있습니다. 외부 엔진은 자동 실행하지 않으므로 첫 번역 시 확인합니다.
4. **번역 엔진**에서 한국어→영어와 영어→한국어에 사용할 모델을 각각 선택할 수 있습니다. 기존 Argos와 OPUS-MT Big은 별도로 설치·보관하며, 미설치 모델을 선택하면 다른 모델로 임의 전환하지 않습니다. 영어↔일본어는 Argos입니다.
5. 일반 입력칸에서 텍스트를 입력하고 단축키를 누릅니다. 문서형 편집기는 선택한 글, 선택이 없으면 현재 문단을 대상으로 시도합니다.

기존 Argos 기본 팩은 한국어→영어, 영어→한국어, 영어→일본어, 일본어→영어입니다. 한국어↔일본어는 영어를 거치며 품질이 떨어질 수 있습니다. 언어팩은 사용자 로컬 폴더에 저장되며 저장소에 포함되지 않습니다. 긴 글은 작은 조각으로 나누어 번역하므로 문맥이 달라질 수 있습니다.

## 선택 가능한 모델

| 모델 | 번역 방향 | 다운로드 / 설치 | 실행 방식 |
| --- | --- | --- | --- |
| Argos 1.1 | 한국어↔영어, 영어↔일본어 | 방향당 약 112~115 MiB 다운로드 | 기존 CTranslate2 INT8 |
| OPUS-MT Big | 한국어→영어, 영어→한국어 | 방향당 약 741 MiB 원본 다운로드 후 로컬 INT8 변환; 설치 약 212 MiB / 8개 파일 | CTranslate2 INT8, 별도 source/target SentencePiece |

OPUS 모델은 University of Helsinki Language Technology Research Group의 [한국어→영어](https://huggingface.co/Helsinki-NLP/opus-mt-tc-big-ko-en), [영어→한국어](https://huggingface.co/Helsinki-NLP/opus-mt-tc-big-en-ko), 2022-07-28 Marian 원본입니다. CC-BY-4.0에 따라 출처·변환 사실을 언어팩에 함께 저장합니다. 변환은 최초 설치 때만 수행하며 PyTorch, Transformers, spaCy, Stanza를 설치하지 않습니다. 원본 다운로드와 변환 중에는 설치 용량보다 많은 임시 디스크·메모리가 필요합니다. 설치는 백그라운드에서 진행하고 진행 상태를 표시합니다.

이름 표기와 주어 등 번역 오류가 발생할 수 있습니다. 모델 크기나 INT8 여부만으로 품질을 보장하지 않습니다. 같은 언어의 모델을 비교·선택할 수 있으며, 자동으로 품질을 판정해 모델을 바꾸지는 않습니다.

## 빠른 입력 직후의 처리

단축키는 두 번째 Shift/Ctrl을 **뗀 시점**에 완성됩니다. 1~2초 고정 대기 없이 최근 일반 키 입력 이후 120ms의 유휴 시간과 두 번의 같은 텍스트/위치 표본을 최소 80ms 간격으로 확인합니다. 대기 중 다시 글을 쓰거나 입력 위치가 바뀌면 그 요청은 취소되며 오래된 타이머가 다시 실행하지 않습니다. 공급자 읽기가 계속 바뀌거나 실패하면 최대 2.2초에서 종료합니다. 이 수치는 실제 편집기에서 IME 조합 완료를 보장하지 않습니다.

프로그램 자체의 선택 변경 이후에는 저장한 live UIA 범위를 원문으로 재사용하지 않고, 새 범위·원문과 실제 Ctrl+C 결과를 확인합니다. Enter나 IME 전환 키로 조합을 강제 확정하지 않습니다.

## 로컬 비교 결과 (2026-10-29)

동일 PC에서 모델별 별도 소스 Python 프로세스, CPU 4스레드, beam 4, 9개 짧은 예문을 각 5회 실행했습니다. 수치는 각 예문의 중앙값 범위입니다.

| 측정 | 기존 Argos INT8 | OPUS-MT Big INT8 |
| --- | --- | --- |
| 한국어→영어 계산 시간 (6문장) | 0.017~0.044초 | 0.032~0.072초 |
| 영어→한국어 계산 시간 (3문장) | 0.017~0.027초 | 0.045~0.066초 |
| 한국어→영어 최초 로딩+첫 번역 | 0.282초 | 0.489초 |
| 두 방향 로딩 후 프로세스 작업 집합 | 350.6 MiB | 528.0 MiB |
| “저는 누구일까요?” | Who are you? (오역) | Who am I? |

일부 한국어 이름은 OPUS에서도 직업명으로 오역했습니다. 작은 자체 예문 집합이며 전체 품질 점수나 모든 이름의 개선을 뜻하지 않습니다. 기존 모델의 세 오역은 FP32로 실행해도 같았습니다. INT8만의 문제라고 볼 근거는 없습니다.

**이 시간은 모델 계산만 측정한 값입니다.** 단축키부터 실제 입력창 교체까지의 시간, 최종 EXE 추출/시작 시간, v0.4 대비 용량·메모리 비교를 뜻하지 않습니다. 입력 안정화의 이미 유휴 상태에서 번역 시작까지는 가상 시계 시험에서 200ms였습니다. 실제 편집기의 응답 시간은 아직 별도 확인이 필요합니다.

## 안전과 제약

- 비밀번호 속성이 확인된 입력창과 읽기 전용 영역을 차단하고, 번역 중 포커스·선택·원문이 변하면 교체를 취소합니다. 프로그램별 접근성 제공 차이 때문에 모든 보안 입력창과 편집기를 식별한다고 보장할 수 없습니다.
- Windows의 키보드 포커스와 UI Automation을 함께 확인합니다. 포커스가 있다고 해서 편집 가능한 것은 아닙니다. 문서 범위는 TextPattern으로 읽고, 실제 선택된 글을 복사해 확인한 후 붙여넣기를 시도합니다. 필요한 기능을 제공하지 않는 프로그램에서는 작동하지 않습니다.
- 범위 붙여넣기는 클립보드를 잠시 사용하고 기존 내용을 복원하려고 합니다. 그 사이 사용자가 클립보드를 바꾸면 새 내용을 덮어쓰지 않습니다. 모든 클립보드 형식과 편집기의 복원·되돌리기는 아직 검증되지 않았습니다.
- 번역 후 커서 위치는 편집기가 제공하는 접근성 기능에 따라 달라질 수 있습니다. 완료 알림은 표시하지 않고 오류는 알립니다.
- 동시에 실행되는 동일 버전은 하나로 제한합니다. 중복 실행 방지 기능이 없는 이전 시험판은 새 버전 실행 전에 트레이에서 모두 종료해야 합니다.
- 기본 번역은 로컬 CTranslate2 INT8 엔진을 사용하며 최근 언어팩 두 개를 메모리에 보관합니다. 결과의 품질과 속도는 언어팩·PC에 따라 다릅니다. 제공 모델과 데이터의 라이선스는 사용자가 해당 배포처에서 확인해야 합니다.

## 사용자 엔진

설정에서 호환되는 사용자 엔진 EXE를 선택할 수 있습니다. 엔진의 표준 입력에는 UTF-8 JSON `{"text":"안녕하세요","source":"ko","target":"en"}`이 전달되고, 표준 출력에는 `{"translation":"Hello"}`가 필요합니다. 지정 형식을 지원하지 않는 일반 EXE는 그대로 사용할 수 없습니다. 원문은 사용자가 선택한 프로그램에 전달되며 인터넷 사용 여부는 해당 엔진에 달려 있습니다. 이 기능도 실제 외부 엔진과의 통합은 미검증입니다.

## 설치형 빌드

설치형은 프로그램 구성 파일을 사용자 폴더에 설치하므로 매번 단일 EXE를 풀지 않습니다. 설정 창은 트레이 아이콘 클릭 또는 실행 파일 재실행으로 다시 열 수 있습니다. `build_windows.bat`은 Python 3.11, Visual Studio C++ Build Tools/Windows SDK, Inno Setup 6이 설치된 개발 PC에서 시험과 설치 파일 생성을 수행합니다. 사용 PC에는 Python과 빌드 도구가 필요 없습니다. TSF DLL은 앱에 로드되므로 매번 새 버전 디렉터리에 설치하며 편집기를 강제로 종료하지 않습니다. 모델 다운로드나 번역이 진행 중이면 업데이트 종료 요청도 작업이 끝날 때까지 기다립니다.

## 빌드

`build_windows.bat`을 실행하면 `dist/STOOM-Translator-v06-TSF-setup.exe`가 생성됩니다. 네이티브 코드를 변경해 배포할 때는 `STOOM_NATIVE_VERSION`을 새 값으로 지정해야 합니다. GitHub Actions의 **Windows build**도 설치형 파일을 빌드하도록 구성되어 있습니다. 실행 파일과 네이티브 서비스는 현재 별도로 서명되어 있지 않습니다.

TSF 설치 구성요소 없이 기존 호환 경로만 포함한 단일 파일을 직접 빌드하려면 다음 명령을 사용합니다.

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m PyInstaller --noconfirm --onefile --windowed --icon stoom.ico --add-data "stoom.ico;." --name STOOMShiftTranslator-v05 main.py
```

## 확인 상태
